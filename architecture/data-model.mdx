## Overview

The `Elementos` class is the core data model in HuelvaPedia, representing individual topics and subtopics. It's designed to work seamlessly with Firebase Realtime Database's automatic object mapping.

**File:** `Elementos.java:1`

```java
package com.example.huelvapedia;

public class Elementos {

    private String ubicacion1;
```

## Field Descriptions

### nombre (String)

**Purpose:** The display name of the topic or subtopic

**Usage:** 
- Displayed as the title in RecyclerView items
- Used for navigation to subtopic screens (passed via Intent to `Secundaria`)

**Example:** "Playas", "Gastronomía", "Lugares de Interés"

### foto (String)

**Purpose:** URL to the item's image hosted on Firebase Storage or external source

**Usage:**
- Loaded into ImageView using Picasso library
- See `Adaptador.java:48`: `Picasso.get().load(elemento.getFoto()).into(holder.imagen)`

**Example:** `"https://firebasestorage.googleapis.com/..."`

### descripcion (String)

**Purpose:** Brief description or summary of the topic

**Usage:**
- Displayed below the name in RecyclerView items
- Provides context about what the user will find

**Example:** "Descubre las mejores playas de Huelva"

### ubicacion1 (String)

**Purpose:** First part of the Google Maps URL (base URL)

**Usage:**
- Combined with `ubicacion2` to create a complete Maps URL
- See `Adaptador.java:76`: `Uri.parse(elemento.getUbicacion1() + Uri.encode(elemento.getUbicacion2()))`

**Example:** `"https://www.google.com/maps/search/?api=1&query="`

**Note:** Can be `null` if the item doesn't have a physical location

### ubicacion2 (String)

**Purpose:** Second part of the location URL (coordinates or place name)

**Usage:**
- URL-encoded and appended to `ubicacion1`
- Opens location in user's preferred maps application

**Example:** `"37.2576,-6.9501"` or `"Plaza de las Monjas, Huelva"`

**Note:** Can be `null` if the item doesn't have a physical location

### telefono (String)

**Purpose:** Phone number for calling the establishment

**Usage:**
- Opens dialer with pre-filled number
- See `Adaptador.java:91`: `Uri.parse("tel:" + elemento.getTelefono())`

**Example:** `"959123456"`

**Note:** Can be `null` if the item doesn't have a contact number

### ultimo (Boolean)

**Purpose:** Flag indicating if this is a leaf node (final detail) or has subtopics

**Usage:**
- **`false`**: Item has subtopics, clicking navigates to `Secundaria` activity
- **`true`**: Item is final detail, only action buttons (map, call, web) are available

**Logic in Adaptador:**

```java
if (!elemento.getUltimo()) {
    // Hide action buttons
    holder.botonUbicacion.setVisibility(View.GONE);
    holder.botonLlamar.setVisibility(View.GONE);
    holder.botonEnlace.setVisibility(View.GONE);

    // Enable navigation to subtopics
    holder.itemView.setOnClickListener(v -> {
        Intent intent = new Intent(v.getContext(), Secundaria.class);
        intent.putExtra("Nombre", elemento.getNombre());
        v.getContext().startActivity(intent);
    });
} else {
    // Show action buttons based on available data
    // (location, phone, link)
}
```

**See:** `Adaptador.java:54-113`

### enlace (String)

**Purpose:** External website URL for more information

**Usage:**
- Opens in browser or user's preferred web handler
- See `Adaptador.java:104-106`: `Intent.ACTION_VIEW` with the link URI

**Example:** `"https://es.wikipedia.org/wiki/Huelva"`

**Note:** Can be `null` if no external link is available

## Firebase Data Mapping

### Automatic Deserialization

Firebase automatically maps JSON objects to `Elementos` instances:

```java
for (DataSnapshot dataSnapshot : snapshot.getChildren()) {
    Elementos elemento = dataSnapshot.getValue(Elementos.class);
    listaElementos.add(elemento);
}
```

**See:** `MainActivity.java:56-60`

### Firebase JSON Structure

Example of how data is structured in Firebase Realtime Database:

```json

    "item1": {
      "nombre": "Playas",
      "foto": "https://example.com/playas.jpg",

      "ubicacion1": null,
```

### Database Reference Structure

<Steps>
  <Step title="Main Topics">
    `FirebaseDatabase.getInstance().getReference().child("principal")`
    
    Loads top-level categories displayed in MainActivity
  </Step>
  
  <Step title="Subtopics">
    `FirebaseDatabase.getInstance().getReference().child(nombreReferencia)`
    
    Where `nombreReferencia` is the topic name normalized (lowercase, no spaces)
  </Step>
</Steps>

<Warning>
