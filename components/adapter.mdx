## Overview

The `Adaptador` class is a custom RecyclerView adapter that manages the display of category and item cards throughout the app. It implements the ViewHolder pattern for efficient view recycling, uses Picasso for image loading, and handles complex conditional logic for navigation and action buttons.

**File Location:** `app/src/main/java/com/example/huelvapedia/Adaptador.java`

## Key Features

- **ViewHolder Pattern**: Efficient view caching and recycling
- **Picasso Integration**: Asynchronous image loading from URLs
- **Conditional UI**: Dynamic button visibility based on item properties
- **Navigation Handling**: Routes to Secundaria activity for subcategories
- **Action Buttons**: Map, call, and web link functionality for leaf nodes
- **Click Listener Support**: Custom click event handling

## Core Adapter Methods

### onCreateViewHolder()

Inflates the item layout and creates a new ViewHolder instance.

```java
@NonNull
@Override
public MiViewHolder onCreateViewHolder(@NonNull ViewGroup parent, int viewType)
{
   View view = LayoutInflater.from(context).inflate(R.layout.principal, parent, false);
   view.setOnClickListener(this);
   return new MiViewHolder(view);
}
```

**Process:**
1. Inflates `R.layout.principal` layout
2. Sets adapter as click listener for the view
3. Creates and returns new `MiViewHolder` instance

### onBindViewHolder()

Binds data to ViewHolder views and configures click behavior based on item properties.

```java
@Override
public void onBindViewHolder(@NonNull MiViewHolder holder, int position)
{
    Elementos elemento = elementos.get(position);

    holder.nombre.setText(elemento.getNombre());
    holder.descripcion.setText(elemento.getDescripcion());
    Picasso.get().load(elemento.getFoto()).into(holder.imagen);

    boolean tieneUbicacion = elemento.getUbicacion1() != null && elemento.getUbicacion2() != null;
    boolean tieneTelefono = elemento.getTelefono() != null;
    boolean tieneEnlace = elemento.getEnlace() != null;

    if (!elemento.getUltimo()) // Not a leaf node - navigates to subcategory
    {
        holder.botonUbicacion.setVisibility(View.GONE);
        holder.botonLlamar.setVisibility(View.GONE);
        holder.botonEnlace.setVisibility(View.GONE);

        if (!tieneUbicacion && !tieneTelefono && !tieneEnlace)
        {
            holder.itemView.setOnClickListener(v -> {
                Intent intent = new Intent(v.getContext(), Secundaria.class);
                intent.putExtra("Nombre", elemento.getNombre());
                v.getContext().startActivity(intent);
            });
        }
    }
    else // Leaf node - shows action buttons
    {
        // Location button (map)
        if (tieneUbicacion)
        {
            holder.botonUbicacion.setOnClickListener(v -> {
                Intent intent = new Intent(Intent.ACTION_VIEW);
                intent.setData(Uri.parse(elemento.getUbicacion1() + Uri.encode(elemento.getUbicacion2())));
                Intent chooser = Intent.createChooser(intent, "Launch Maps");
                v.getContext().startActivity(chooser);
            });
        }
        else
        {
            holder.botonUbicacion.setVisibility(View.GONE);
        }

        // Phone button (call)
        if (tieneTelefono)
        {
            holder.botonLlamar.setOnClickListener(v -> {
                Intent intent = new Intent(Intent.ACTION_DIAL);
                intent.setData(Uri.parse("tel:" + elemento.getTelefono()));
                v.getContext().startActivity(intent);
            });
        }
        else
        {
            holder.botonLlamar.setVisibility(View.GONE);
        }

        // Web link button
        if (tieneEnlace)
        {
            holder.botonEnlace.setOnClickListener(v -> {
                Uri link = Uri.parse(elemento.getEnlace());
                Intent intent = new Intent(Intent.ACTION_VIEW, link);
                v.getContext().startActivity(intent);
            });
        }
        else
        {
            holder.botonEnlace.setVisibility(View.GONE);
        }
    }
}
```

## ViewHolder Implementation

Internal static class that holds references to item views.

```java
static class MiViewHolder extends RecyclerView.ViewHolder
{
    TextView nombre, descripcion;
    ImageView imagen;
    Button botonUbicacion, botonLlamar, botonEnlace;

    public MiViewHolder(@NonNull View itemView)
    {
        super(itemView);

        nombre = itemView.findViewById(R.id.tenombre);
        descripcion = itemView.findViewById(R.id.tedescri);
        imagen = itemView.findViewById(R.id.imagen);
        botonUbicacion = itemView.findViewById(R.id.botonubi);
        botonLlamar = itemView.findViewById(R.id.botonllamar);
        botonEnlace = itemView.findViewById(R.id.botonwiki);
    }
}
```

**Cached Views:**
- `nombre` - Item title
- `descripcion` - Item description
- `imagen` - Item image
- `botonUbicacion` - Map/location button
- `botonLlamar` - Phone call button
- `botonEnlace` - Web link button

```java

```

**Features:**
- Asynchronous image downloading
- Automatic caching (memory and disk)
- Error placeholder support (not implemented)
- Memory-efficient bitmap handling

// Recommended implementation with placeholders and error handling
Picasso.get()
    .load(elemento.getFoto())
    .placeholder(R.drawable.placeholder_image)  // Shown while loading
    .error(R.drawable.error_image)              // Shown on load failure

    .into(holder.imagen);

if (tieneUbicacion)

## Action Button Implementations

### Location Button (Map)

```java
holder.botonUbicacion.setOnClickListener(v -> {
    Intent intent = new Intent(Intent.ACTION_VIEW);
    intent.setData(Uri.parse(elemento.getUbicacion1() + Uri.encode(elemento.getUbicacion2())));
    Intent chooser = Intent.createChooser(intent, "Launch Maps");
    v.getContext().startActivity(chooser);
});
```

**Functionality:**
- Constructs map URL from `ubicacion1` + `ubicacion2`
- Encodes second part to handle special characters
- Creates chooser dialog for map apps
- Opens in Google Maps, Apple Maps, or other installed map apps

**Example:**
- `ubicacion1`: `"https://www.google.com/maps/search/?api=1&query="`
- `ubicacion2`: `"Plaza de las Monjas, Huelva"`
- Result: `https://www.google.com/maps/search/?api=1&query=Plaza+de+las+Monjas%2C+Huelva`

### Phone Button (Call)

```java
holder.botonLlamar.setOnClickListener(v -> {
    Intent intent = new Intent(Intent.ACTION_DIAL);
    intent.setData(Uri.parse("tel:" + elemento.getTelefono()));
    v.getContext().startActivity(intent);
});
```

**Functionality:**
- Uses `ACTION_DIAL` (opens dialer, doesn't call automatically)
- Prefixes phone number with `tel:` scheme
- Respects user privacy (requires explicit dial action)

**Example:**
- Phone: `"959123456"`
- URI: `tel:959123456`

<Note>
Uses `ACTION_DIAL` instead of `ACTION_CALL` to avoid requiring `CALL_PHONE` permission and to let users confirm before calling.
</Note>

### Web Link Button

```java
holder.botonEnlace.setOnClickListener(v -> {
    Uri link = Uri.parse(elemento.getEnlace());
    Intent intent = new Intent(Intent.ACTION_VIEW, link);
    v.getContext().startActivity(intent);
});
```

**Functionality:**
- Opens URL in default browser
- Supports http, https, and other URI schemes
- No chooser dialog (uses default browser directly)

## Click Listener Management

```java
public void setOnClickListener(View.OnClickListener listener)
{
    this.listener = listener;
}

@Override
public void onClick(View v) {
    if (listener != null)
    {
        listener.onClick(v);
    }
}
```

Allows external click handling if needed, though current implementation handles clicks internally.
