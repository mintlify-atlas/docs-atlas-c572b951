## Overview

The `MainActivity` serves as the app's main interface, displaying top-level categories retrieved from Firebase Realtime Database. It uses a RecyclerView with a custom adapter to present category cards and includes a button to access the weather activity.

**File Location:** `app/src/main/java/com/example/huelvapedia/MainActivity.java`

## Key Features

- **Firebase Integration**: Real-time data synchronization from Firebase Realtime Database
- **RecyclerView Display**: Efficient list rendering of category items
- **Custom Adapter**: Uses Adaptador class for ViewHolder pattern implementation
- **Weather Navigation**: Direct access to weather information for Huelva
- **Branded Action Bar**: Displays Huelva coat of arms icon

## onCreate() Method

Initializes the activity, sets up UI components, configures Firebase listener, and establishes navigation.

```java
@Override
protected void onCreate(Bundle savedInstanceState)
{
    super.onCreate(savedInstanceState);
    setContentView(R.layout.activity_main);

    botonTiempo = findViewById(R.id.botontiempo);

    ActionBar actionBar = getSupportActionBar();
    actionBar.setIcon(R.mipmap.ic_escudohuelva);
    actionBar.setDisplayShowHomeEnabled(true);

    recyclerView = findViewById(R.id.recicler);
    recyclerView.setLayoutManager(new LinearLayoutManager(this));

    listaElementos = new ArrayList<>();

    reference = FirebaseDatabase.getInstance().getReference().child("principal");

    reference.addValueEventListener(new ValueEventListener()
    {
        @Override
        public void onDataChange(@NonNull DataSnapshot snapshot)
        {
            listaElementos.clear(); // Prevents data duplication on Firebase updates
            for (DataSnapshot dataSnapshot : snapshot.getChildren())
            {
                Elementos elemento = dataSnapshot.getValue(Elementos.class);
                listaElementos.add(elemento);
            }
            adaptador = new Adaptador(MainActivity.this, listaElementos);
            recyclerView.setAdapter(adaptador);
        }

        @Override
        public void onCancelled(@NonNull DatabaseError error)
        {
            Toast.makeText(MainActivity.this, "Algo ha fallado", Toast.LENGTH_SHORT).show();
        }
    });

    botonTiempo.setOnClickListener(v -> {
        Intent intent = new Intent(v.getContext(), Tiempo.class);
        startActivity(intent);
    });
}
```

## Data Flow

1. **Activity Creation** → onCreate() initializes UI and Firebase reference
2. **Firebase Connection** → Establishes listener on "principal" database node
3. **Data Reception** → onDataChange() receives category data
4. **Data Processing** → Converts DataSnapshot to Elementos objects
5. **Adapter Creation** → Instantiates Adaptador with category list
6. **UI Update** → RecyclerView displays categories via adapter
7. **User Interaction** → Categories clickable via Adaptador click handling

## Firebase Database Structure

```
Firebase Root
└── principal
    ├── category1
    │   ├── nombre: "Category Name"
    │   ├── descripcion: "Description"
    │   ├── foto: "https://..."
    │   └── ultimo: false
    ├── category2
    │   └── ...
    └── category3
        └── ...
```

<Note>
The activity uses `addValueEventListener()` which maintains a persistent connection to Firebase, automatically updating the UI when data changes in the database.
</Note>

<Warning>
The listener clears and recreates the adapter on every data change. For large datasets with frequent updates, consider using a more efficient update mechanism like DiffUtil.
</Warning>
