## Overview

This guide will walk you through cloning the HuelvaPedia repository, opening it in Android Studio, and building the project. The setup process is straightforward, but requires Firebase configuration before you can run the app.

<Warning>
  The `google-services.json` file is **not included** in the repository for security reasons. You'll need to set up your own Firebase project. See the [Firebase Setup](/firebase-setup) guide for detailed instructions.
</Warning>

## Installation Steps

<Steps>
  <Step title="Clone the Repository">
    Open your terminal and clone the HuelvaPedia repository:
    
    ```bash
    git clone https://github.com/JuancaCalvino/HuelvaPedia.git
    ```
    
    This will create a local copy of the project in your current directory.
  </Step>
  
  <Step title="Open Project in Android Studio">
    Launch Android Studio and open the project:
    
    1. Click **File > Open...** from the menu bar
    2. Navigate to the cloned `HuelvaPedia` folder
    3. Select the folder and click **OK**
    
    Android Studio will begin loading the project and indexing files.
  </Step>
  
  <Step title="Wait for Gradle Sync">
    Android Studio will automatically start syncing Gradle dependencies. This process may take a few minutes depending on your internet connection.
    
    <Note>
      If Gradle sync fails due to missing `google-services.json`, this is expected. Continue to the Firebase Setup step to resolve this.
    </Note>
    
    The project uses:
    - **Gradle Plugin:** 7.4.2
    - **Google Services Plugin:** 4.3.15
    - **Java Compatibility:** Version 1.8
  </Step>
  
  <Step title="Configure Firebase (Required)">
    Before you can build the app, you must connect it to your own Firebase project and add the `google-services.json` configuration file.
    
    Follow the complete [Firebase Setup Guide](/firebase-setup) to:
    - Create a Firebase project
    - Register your Android app with package name `com.example.huelvapedia`
    - Download and place the `google-services.json` file
    - Set up the Realtime Database structure
  </Step>
  
  <Step title="Build and Run">
    Once Firebase is configured and Gradle sync completes successfully:
    
    1. Connect an Android device via USB with USB debugging enabled, or start an Android emulator
    2. Click the **Run 'app'** button (▶) in the toolbar, or press `Shift + F10`
    3. Select your target device from the deployment target dialog
    4. Wait for the build to complete and the app to launch
  </Step>
</Steps>

## Device Requirements

### Minimum Requirements

- **Android Version:** 8.1 (Oreo) or higher
- **API Level:** 27 or higher
- **Internet Connection:** Required for all app functionality

### Supported Screen Sizes

The app supports small and normal screen sizes with the following densities:
- ldpi (low density)
- mdpi (medium density)
- hdpi (high density)
- xhdpi (extra high density)

### Required Permissions

The app requires the following permissions, declared in `AndroidManifest.xml`:

```xml AndroidManifest.xml
<uses-permission android:name="android.permission.INTERNET"/>
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE"/>
```

- **INTERNET:** Required to fetch data from Firebase Realtime Database
- **ACCESS_NETWORK_STATE:** Used to check network connectivity status

## Troubleshooting

### Gradle Sync Failed

If Gradle sync fails, try:
1. Ensure you're using Android Studio Electric Eel or newer
2. Check that you have Java JDK 11 or higher installed
3. Verify your internet connection
4. Click **File > Invalidate Caches** and restart Android Studio

### Missing google-services.json

If you see an error about missing `google-services.json`:
1. This file is intentionally excluded from version control
2. You must create your own Firebase project
3. Follow the [Firebase Setup Guide](/firebase-setup) to generate this file

### Build Errors

If the build fails after adding `google-services.json`:
1. Clean the project: **Build > Clean Project**
2. Rebuild: **Build > Rebuild Project**
3. Ensure the package name in your Firebase project matches `com.example.huelvapedia`
