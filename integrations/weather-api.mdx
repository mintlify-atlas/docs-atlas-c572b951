## Overview

The Tiempo (Weather) feature integrates with the OpenWeatherMap API to display real-time weather information for Huelva, Spain. The integration uses the Volley library for HTTP requests and parses JSON responses to extract weather data.

## Dependencies

Add the Volley library to your `app/build.gradle`:

```gradle app/build.gradle
implementation 'com.android.volley:volley:1.2.1'
```

## API Configuration

### API Endpoint

```java Tiempo.java
private static final String URL_BASE = "http://api.openweathermap.org/data/2.5/weather";
private static final String API_KEY = "c0d138083fb0634d6d5cd36adafc9a77";
```

<Warning>
  The API key should be moved to `local.properties` and accessed via `BuildConfig` to avoid exposing credentials in version control.
</Warning>

### Building the Request URL

```java Tiempo.java
String urlCompleta = URL_BASE + "?q=Huelva,ES&appid=" + API_KEY;
```

Parameters:
- `q=Huelva,ES` - City name and country code
- `appid` - Your OpenWeatherMap API key

## Making API Requests with Volley

### StringRequest Implementation

```java Tiempo.java
StringRequest stringRequest = new StringRequest(Request.Method.POST, urlCompleta,
    response -> {
        try {
            JSONObject jsonResponse = new JSONObject(response);
            // Parse response (see JSON parsing section)
        } catch (JSONException e) {
            e.printStackTrace();
        }
    },
    error -> Toast.makeText(getApplicationContext(), 
        error.toString().trim(), Toast.LENGTH_SHORT).show()
);

RequestQueue requestQueue = Volley.newRequestQueue(getApplicationContext());
requestQueue.add(stringRequest);
```

### Request Components

1. **Request Method** - `Request.Method.POST`
2. **URL** - Complete API endpoint with parameters
3. **Success Listener** - Lambda handling JSON response
4. **Error Listener** - Lambda displaying error messages

## JSON Parsing

### Extracting Weather Data

<CodeGroup>

```java Weather Description
JSONObject jsonResponse = new JSONObject(response);
JSONArray jsonArray = jsonResponse.getJSONArray("weather");
JSONObject jsonObjectWeather = jsonArray.getJSONObject(0);
String descripcion = jsonObjectWeather.getString("description");
```

```java Temperature Data
JSONObject jsonObjectMain = jsonResponse.getJSONObject("main");
double temp = jsonObjectMain.getDouble("temp") - 273.15;
double sensacion = jsonObjectMain.getDouble("feels_like") - 273.15;
float presion = jsonObjectMain.getInt("pressure");
int humedad = jsonObjectMain.getInt("humidity");
```

```java Wind and Clouds
JSONObject jsonObjectWind = jsonResponse.getJSONObject("wind");
String viento = jsonObjectWind.getString("speed");

JSONObject jsonObjectClouds = jsonResponse.getJSONObject("clouds");
String nubes = jsonObjectClouds.getString("all");
```

</CodeGroup>

## Temperature Conversion

OpenWeatherMap returns temperatures in Kelvin by default. Convert to Celsius:

```java Tiempo.java
double temp = jsonObjectMain.getDouble("temp") - 273.15;
double sensacion = jsonObjectMain.getDouble("feels_like") - 273.15;

// Format and display
tvTemperatura.setText(formatoDecimal.format(temp) + "ºC");
tvSensacion.setText("Sensacion térmica: " + formatoDecimal.format(sensacion) + "ºC");
```

### Decimal Formatting

```java Tiempo.java
private final DecimalFormat formatoDecimal = new DecimalFormat("#.#");
```

## Weather Description Translation

The app includes a method to translate English weather descriptions to Spanish and set corresponding weather icons:

```java Tiempo.java
private void traducirDescripcion(String descripcion)
{
    switch (descripcion)
    {
        case "clear sky":
            tvDescripcion.setText("Despejado");
            imagenDelTiempo.setImageResource(R.mipmap.ic_soleado);
            break;
        case "few clouds":
            tvDescripcion.setText("Ligeramente nublado");
            imagenDelTiempo.setImageResource(R.mipmap.ic_ligeramentenublado);
            break;
        case "scattered clouds":
            tvDescripcion.setText("Nubes dispersas");
            imagenDelTiempo.setImageResource(R.mipmap.ic_nubesdispersas);
            break;
        case "overcast clouds":
            tvDescripcion.setText("Nublado");
            imagenDelTiempo.setImageResource(R.mipmap.ic_nublado);
            break;
        case "light rain":
            tvDescripcion.setText("Lluvia ligera");
            imagenDelTiempo.setImageResource(R.mipmap.ic_lluvialigera);
            break;
        case "broken clouds":
            tvDescripcion.setText("Nubes rotas");
            imagenDelTiempo.setImageResource(R.mipmap.ic_nubesrotas);
            break;
        case "heavy intensity rain":
            tvDescripcion.setText("Lluvia pesada");
            imagenDelTiempo.setImageResource(R.mipmap.ic_lluviafuerte);
            break;
        case "moderate rain":
            tvDescripcion.setText("Lluvia moderada");
            imagenDelTiempo.setImageResource(R.mipmap.ic_lluviamoderada);
            break;
    }
}
```

## API Response Structure

The OpenWeatherMap API returns JSON with the following structure:

```json
{
  "weather": [
    {
      "description": "clear sky"
    }
  ],
  "main": {
    "temp": 295.15,
    "feels_like": 294.15,
    "pressure": 1013,
    "humidity": 65
  },
  "wind": {
    "speed": 3.5
  },
  "clouds": {
    "all": 20
  }
}
```

## Error Handling

The implementation includes two error handling mechanisms:

1. **Network/API Errors** - Handled by Volley's error listener
2. **JSON Parsing Errors** - Caught with try-catch for JSONException

```java Tiempo.java
error -> Toast.makeText(getApplicationContext(), 
    error.toString().trim(), Toast.LENGTH_SHORT).show()
```

## Best Practices

<Tip>
  Store API keys in `local.properties` and access them via `BuildConfig` to keep credentials secure and out of version control.
</Tip>

<Warning>
  Always handle both network errors and JSON parsing exceptions to prevent app crashes when the API is unavailable or returns unexpected data.
</Warning>
