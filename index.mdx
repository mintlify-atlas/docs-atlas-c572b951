## Key Features

<CardGroup cols={2}>
  <Card title="Cloud-Based Data" icon="cloud" iconType="solid">
    All information is fetched dynamically from Firebase Realtime Database, ensuring data is always up-to-date without app updates
  </Card>
  <Card title="Categorized Information" icon="grid" iconType="solid">
    Browse through different aspects of Huelva including history, gastronomy, and places of interest
  </Card>
  <Card title="Real-Time Weather" icon="sun" iconType="solid">

## Tech Stack

<Note>
  **Language:** Java  
  **Minimum SDK:** API 27 (Android 8.1 - Oreo)  
  **Target SDK:** API 30 (Android 11)  
  **Backend:** Google Firebase Realtime Database  
  **Network Requests:** Android Volley  
  **Image Loading:** Picasso  
  **UI Components:** AndroidX, Material Design, ConstraintLayout, CardView
</Note>
