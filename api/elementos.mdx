## Overview

`Elementos` is a Plain Old Java Object (POJO) class designed to store the elements that compose each topic in the HuelvaPedia application. It contains properties for name, photo, description, location, phone, and web link information.

## Class Signature

```java
public class Elementos
```

**Package:** `com.example.huelvapedia`

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `nombre` | `String` | Name of the element |
| `foto` | `String` | URL or path to the photo |
| `descripcion` | `String` | Description text |
| `ubicacion1` | `String` | First part of location (base URL) |
| `ubicacion2` | `String` | Second part of location (address to encode) |
| `telefono` | `String` | Phone number |
| `ultimo` | `Boolean` | Flag indicating if this is the last element (affects UI behavior) |
| `enlace` | `String` | Web link URL |

## Usage Notes

The `ultimo` field plays a special role in the UI:
- When `false`: The item navigates to the Secundaria activity when clicked
- When `true`: The item displays action buttons (location, phone, web link) based on available data
