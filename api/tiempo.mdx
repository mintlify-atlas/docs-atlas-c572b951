## Overview

`Tiempo` is an activity that displays current weather information for Huelva, Spain. It fetches data from the OpenWeatherMap API using Volley, parses JSON responses, and displays temperature, weather conditions, humidity, pressure, wind speed, and cloud coverage.

<Accordion title="onCreate()">
  ```java
  @Override
  protected void onCreate(Bundle savedInstanceState)
  ```
  
  Initializes the weather activity:
  
  1. **Binds UI components** from layout (`activity_tiempo`):
     - TextViews for all weather data fields
     - ImageView for weather icon
  
  2. **Configures ActionBar**:
     - Sets Huelva icon (`R.mipmap.ic_escudohuelva`)
     - Enables home display
  
  3. **Constructs API URL**:
     ```java
     String urlCompleta = URL_BASE + "?q=Huelva,ES&appid=" + API_KEY;
     ```
  
  4. **Creates Volley StringRequest** (POST method):
     - **On success**: Parses JSON response and updates UI
     - **On error**: Displays error toast
  
  5. **Parses JSON response**:
     - Extracts weather description from `weather` array
     - Extracts temperature, feels-like, pressure, humidity from `main` object
     - Extracts wind speed from `wind` object
     - Extracts cloud coverage from `clouds` object
     - Converts temperature from Kelvin to Celsius (subtracts 273.15)
  
  6. **Updates UI**:
     - Calls `traducirDescripcion()` to translate and set weather icon
     - Sets all TextViews with formatted weather data
  
  7. **Executes request** using Volley RequestQueue

## JSON Response Structure

The activity expects the following JSON structure from OpenWeatherMap API:

```json
{
  "weather": [
    {
      "description": "clear sky"
    }
  ],
  "main": {
    "temp": 293.15,
    "feels_like": 292.15,
    "pressure": 1013,
    "humidity": 65
  },
  "wind": {
    "speed": "3.5"
  },
  "clouds": {
    "all": "20"
  }
}
```

## API Request Details

### Full URL Format
```
http://api.openweathermap.org/data/2.5/weather?q=Huelva,ES&appid=c0d138083fb0634d6d5cd36adafc9a77
```

### Request Method
`POST` (via `Request.Method.POST`)

### Query Parameters
- `q`: "Huelva,ES" (city and country code)
- `appid`: API key for authentication

## Temperature Conversion

Temperatures are converted from Kelvin (API format) to Celsius:

```java
double temp = jsonObjectMain.getDouble("temp") - 273.15;
double sensacion = jsonObjectMain.getDouble("feels_like") - 273.15;
```

Formatted using `DecimalFormat("#.#")` for display.
