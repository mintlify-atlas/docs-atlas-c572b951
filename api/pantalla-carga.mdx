## Overview

`PantallaCarga` is the splash screen activity that displays when the app launches. It checks for internet connectivity, displays loading animations, and navigates to the main activity after a delay. If no connection is detected, it monitors connectivity and proceeds once available.

## Connectivity Methods

<Accordion title="checkConnectivity()">
  ```java
  private void checkConnectivity()
  ```
  
  Checks the current network connectivity state:
  
  **If connected:**
  - Sets `hayConexion` to `true`
  - Schedules navigation to MainActivity after `DURACION_CARGA` milliseconds
  
  **If not connected:**
  - Sets `hayConexion` to `false`
  - Displays toast message: "SE DEBE DISPONER DE CONEXIÓN A INTERNET"
  - Registers `NetworkCallback` to monitor for connection
  - Sets `monitorizando` to `true`
  
  Uses `ConnectivityManager` and `NetworkInfo` to check active network status.
  
  **Location:** `PantallaCarga.java:62`
</Accordion>

## Network Request Configuration

The activity registers a `NetworkCallback` with the following capabilities:

```java
new NetworkRequest.Builder()
    .addCapability(NetworkCapabilities.NET_CAPABILITY_INTERNET)
    .build()
```

## Flow Diagram

1. **onCreate()** → Initialize UI and animations
2. **checkConnectivity()** → Check network status
3. **If connected** → Schedule navigation after 5 seconds
4. **If not connected** → Show toast, register NetworkCallback
5. **When network available** → Navigate to MainActivity
6. **onPause()/onDestroy()** → Clean up callbacks and handlers
