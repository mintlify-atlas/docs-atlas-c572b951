## Overview

`Adaptador` is a `RecyclerView.Adapter` implementation that displays a list of `Elementos` objects. It handles dynamic UI behavior including button visibility based on available data and the `ultimo` field, as well as click handling for navigation and actions.

## Class Signature

```java
public class Adaptador extends RecyclerView.Adapter<Adaptador.MiViewHolder> 
                       implements View.OnClickListener
```

**Package:** `com.example.huelvapedia`

**Extends:** `RecyclerView.Adapter<Adaptador.MiViewHolder>`

**Implements:** `View.OnClickListener`

<Accordion title="onBindViewHolder()">
  ```java
  @Override
  public void onBindViewHolder(@NonNull MiViewHolder holder, int position)
  ```
  
  Binds data to the ViewHolder at the specified position. Implements complex logic for:
  - Setting text and image data using Picasso
  - Checking for available data (location, phone, web link)
  - Button visibility based on the `ultimo` field
  - Click handlers for navigation and action buttons
  
  ### Behavior Logic:
  
  **When `ultimo` is `false`:**
  - All action buttons are hidden
  - If no location, phone, or link data exists, clicking navigates to `Secundaria` activity
  
  **When `ultimo` is `true`:**
  - Location button: Shows if `ubicacion1` and `ubicacion2` are not null, launches maps
  - Phone button: Shows if `telefono` is not null, launches dialer
  - Web link button: Shows if `enlace` is not null, opens browser
  
  <ParamField path="holder" type="MiViewHolder">
    The ViewHolder to bind data to
  </ParamField>
  
  <ParamField path="position" type="int">
    Position of the item in the dataset
  </ParamField>
  
  **Location:** `Adaptador.java:42`
</Accordion>

## Action Button Intents

### Location Button
```java
Intent intent = new Intent(Intent.ACTION_VIEW);
intent.setData(Uri.parse(elemento.getUbicacion1() + Uri.encode(elemento.getUbicacion2())));
Intent chooser = Intent.createChooser(intent, "Launch Maps");
v.getContext().startActivity(chooser);
```

### Phone Button
```java
Intent intent = new Intent(Intent.ACTION_DIAL);
intent.setData(Uri.parse("tel:" + elemento.getTelefono()));
v.getContext().startActivity(intent);
```

### Web Link Button
```java
Uri link = Uri.parse(elemento.getEnlace());
Intent intent = new Intent(Intent.ACTION_VIEW, link);
v.getContext().startActivity(intent);
```
