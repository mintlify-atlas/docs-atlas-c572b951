## What is HuelvaPedia?

HuelvaPedia is an Android application that serves as a comprehensive digital encyclopedia for the province and city of Huelva, Spain. The app provides users with rich, categorized information about the region's cultural heritage, historical landmarks, local gastronomy, and points of interest.

Built with modern Android development practices and powered by Firebase Realtime Database, HuelvaPedia delivers a lightweight, cloud-based experience that keeps content fresh without requiring constant app updates.

## Technology Stack

HuelvaPedia is built with industry-standard Android technologies:

- **Language:** Java
- **Backend/Database:** Google Firebase Realtime Database
- **Network Requests:** Android Volley for efficient API communication
- **Image Loading:** Picasso for optimized image rendering
- **UI Components:** AndroidX, Material Design, ConstraintLayout, CardView

## Prerequisites

Before you begin, ensure you have the following:

<Steps>
  <Step title="Android Studio">
    Android Studio Electric Eel or newer is recommended for the best development experience
  </Step>
  
  <Step title="Android SDK">
    Android SDK with API level 30 or higher installed
  </Step>
  
  <Step title="Java JDK">
    Java JDK 11 or higher, depending on your Gradle JVM setting
  </Step>
  
  <Step title="Physical Device or Emulator">
    An Android device or emulator running Android 8.1 (Oreo) or higher
  </Step>
  
  <Step title="Internet Connection">
    An active internet connection is required for the app to function, as all content is hosted in the cloud
  </Step>
</Steps>

<Note>
  **Minimum Android Version:** The app requires Android 8.1 (API 27) or higher to run
</Note>

## Platform Requirements

- **Minimum SDK:** API 27 (Android 8.1 - Oreo)
- **Target SDK:** API 30 (Android 11)
